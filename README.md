# 주간보고서 자동 작성

Jira에서 **내게 할당된 업무**를 가져와 Confluence에 보고서를 만들어 줍니다.
처음 한 번만 설정하면 매주 수요일 오후 4시에 자동으로 실행할 수 있습니다.

## 1. 내려받기

이 페이지 위쪽의 **초록색 `Code` 버튼 → `Download ZIP`**을 누르세요.

받은 ZIP 파일을 마우스 오른쪽 버튼으로 눌러 **모두 압축 풀기**를 선택하세요.
압축을 푼 폴더는 `문서` 등 계속 사용할 곳에 두세요.

> Windows PC에서 사용합니다. Jira와 Confluence를 같은 회사 Atlassian 사이트에서 사용하고, 보고서를 쓸 권한이 있어야 합니다. 별도 프로그램 설치는 필요 없습니다.

## 2. 처음 한 번 설정하기

압축을 푼 폴더에서 **`처음설정.cmd`를 더블클릭**하세요.
검은 창이 열리면 아래 네 가지를 차례로 입력합니다.

| 물어보는 것 | 입력할 내용 |
| --- | --- |
| 이름 | 보고서에 표시할 본인 이름 |
| 이메일 | Jira에 로그인할 때 사용하는 이메일 |
| API 토큰 | 아래 링크에서 발급한 토큰 |
| Confluence 주소 | 보고서를 모아 둘 폴더나 상위 페이지를 열고 복사한 브라우저 주소 |

**API 토큰이 없다면:** [토큰 발급 페이지](https://id.atlassian.com/manage-profile/security/api-tokens)에 로그인해 **범위 없는 API 토큰**을 만들고 복사하세요. 토큰은 비밀번호처럼 다루세요. 입력하거나 붙여넣어도 화면에 글자가 보이지 않는 것이 정상입니다.

**Confluence 주소는:** 보고서를 저장할 폴더나 페이지를 직접 열고, 브라우저 맨 위 주소창에서 복사하세요. '공유' 버튼으로 만든 짧은 링크는 사용하지 마세요. 숫자로 된 ID를 따로 찾을 필요는 없습니다.

다음 질문에는 이렇게 답하면 됩니다. `y`를 입력한 뒤 Enter를 누르세요.

1. **지금 보고서를 생성해 확인할까요?** → `y` → Confluence에 보고서가 생겼는지 확인하세요.
2. **매주 수요일 오후 4시 자동 실행을 등록할까요?** → 자동 실행을 원하면 `y`.

건너뛰려면 `y` 대신 Enter만 누르세요. **'설정 완료'가 나오면 끝입니다.**

## 3. 다음부터 사용하기

- **예약 실행:** 매주 수요일 오후 4시에 실행합니다. PC가 켜져 있고 본인 Windows 계정에 로그인되어 있어야 합니다.
- **지금 바로 만들기:** `지금실행.cmd`를 더블클릭하세요.
- **계정이나 저장 위치 바꾸기:** `처음설정.cmd`를 다시 실행하세요.

보고서 제목은 `2026-11-11 (본인 이름)`처럼 만들어집니다. 실행 창과 `weekly_report.log`에서 보고서 주소를 확인할 수 있습니다.

> **같은 날 다시 실행하면 기존 보고서 내용을 전부 덮어씁니다.** 보고서에 직접 적은 내용과 차주 업무도 지워지므로 주의하세요.

## 어떤 파일을 열어야 하나요?

**처음에는 `처음설정.cmd`, 이후에는 `지금실행.cmd`만 열면 됩니다.**

`app` 폴더는 프로그램이고, `개발용` 폴더는 자세한 설명과 검사 도구입니다. 둘 다 열거나 수정할 필요가 없습니다. 기본 설정은 자동으로 만들어지므로 파일을 복사하거나 이름을 바꿀 필요도 없습니다.

설정 후 생기는 `weekly_report.config.psd1`에는 개인 토큰이 들어 있습니다. **이 파일이나 설정이 끝난 폴더 전체를 팀원에게 보내지 마세요.** 팀원에게는 이 GitHub 페이지를 알려 주세요.

## 잘 안 되면

| 상황 | 먼저 해 볼 일 |
| --- | --- |
| 실행이 안 됨 | ZIP 안에서 실행하지 말고 압축을 완전히 푼 뒤 실행하세요. `app` 폴더도 함께 있어야 합니다. |
| 인증 실패 / 401 | 본인 이메일과 토큰을 확인하고 `처음설정.cmd`로 다시 입력하세요. |
| 권한 없음 / 403 | Jira 조회 권한과 Confluence에 보고서를 쓸 권한을 확인하세요. |
| 저장 실패 / 404 | 저장할 Confluence 폴더나 상위 페이지의 실제 주소를 다시 확인하세요. |
| 자동으로 실행되지 않음 | PC 켜짐·로그인 여부를 확인하세요. 설치 폴더를 옮겼다면 자동 실행을 다시 등록해야 합니다. |

오류를 문의할 때는 화면의 오류 문구를 알려 주세요. **API 토큰은 보내지 마세요.**

분류 변경, 업데이트, 자동 실행 해제 등은 [자세한 설정 안내](개발용/설정안내.md)를 참고하세요.
